clanker-analytics now runs on [DuckDB](https://duckdb.org/) 2.0, adds a `model-rates` command that prices each model's use of a subscription quota, and counts [AOP (agent-orchestration-process)](https://github.com/wakamex/agent-orchestration-process) runs of Claude Code and Antigravity at the time of each model call.

- DuckDB 2.0 rejects the old `x -> expr` lambda syntax and removes `fetchone()` from query results, so every command failed with v0.5.6 once DuckDB 2.0 was installed. This release works on DuckDB 1.5 and 2.0 ([`ecfd9e6`](https://github.com/wakamex/clanker-analytics/commit/ecfd9e684354716e4332eeed9cf6a75750ca4ca9)).
- `model-rates` estimates the API-equivalent dollars of each model's usage that raise a quota window by one percentage point, across all of a provider's accounts on one plan, with 95% ranges. Each model's price is checked against the stretches it ran alone, and against fits of each half of the window, so a model that disagrees or whose price changed is flagged. On one host it gives Claude Opus 5.5 $28.98 a weekly point and Antigravity's Gemini 4 Carbon $1.99 ([`55c27e2`](https://github.com/wakamex/clanker-analytics/commit/55c27e2543d4ff27f0d4f88f92be64471f6f760d), [`b413b14`](https://github.com/wakamex/clanker-analytics/commit/b413b14c079072ae1a60fecd1a24d355eec05361), [`a34fab5`](https://github.com/wakamex/clanker-analytics/commit/a34fab53e27c1323148def7c9818d5f65937fcf1)).
- AOP runs Claude Code and Antigravity in a private home inside each run's state root. clanker-analytics now reads those homes, listed in AOP's `state-roots` file, so a run's usage counts while it runs and at each call's own time, instead of as one total at the run's start once it ends. The run keeps the project AOP attributes it to ([`f6e101f`](https://github.com/wakamex/clanker-analytics/commit/f6e101fe98f0835e3a3523e697b424e96e09cb2e), [`b0f0a24`](https://github.com/wakamex/clanker-analytics/commit/b0f0a244bbcd6393906412defc658759ca69033c), [`27c7c0f`](https://github.com/wakamex/clanker-analytics/commit/27c7c0f540c38e1df4441a18bc7e65286a920ed9)).
- `record-quota` records OpenCode, Cursor and Devin quota ([`834ed1f`](https://github.com/wakamex/clanker-analytics/commit/834ed1fd646815d105262c6411e9fcec121f9996)), and a running Antigravity conversation counts before Antigravity's index lists it ([`b237523`](https://github.com/wakamex/clanker-analytics/commit/b2375235747455f0c180f7ec9f9ef8bd9de45af5)).
- `pace` runs about four times faster, 27 seconds instead of 103 on one host ([`d4106d3`](https://github.com/wakamex/clanker-analytics/commit/d4106d327255822a8473f37ae48388d7f43d9436)), and `table` leaves out columns that say nothing about the rows shown, such as first and last seen over the last 24 hours ([`3f2966d`](https://github.com/wakamex/clanker-analytics/commit/3f2966da0120939fe569abed933fbc3d3d77e04f)).
- clanker-analytics requires [model-prices](https://github.com/wakamex/model-prices) 0.0.10, which prices Claude Fable 5.2 ([`57f0044`](https://github.com/wakamex/clanker-analytics/commit/57f004457b684b2c182edf0a54d4d8a97ebf7c42)), and declares numpy, which it already installed through matplotlib.
