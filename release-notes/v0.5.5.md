clanker-analytics now reads [OpenCode](https://opencode.ai/) usage from OpenCode's own database, thanks to [@Microck](https://github.com/Microck) in [#1](https://github.com/wakamex/clanker-analytics/pull/1), and gives each quota window a stable price.

- OpenCode: each assistant message in `${XDG_DATA_HOME:-~/.local/share}/opencode/opencode*.db` (or the file `OPENCODE_DB` names) is one model call, with its model named `provider/model` and child sessions counted as subagents. Output is taken from each message's total, so OpenAI models' reasoning, which OpenCode records inside output, counts once. Sessions outside a git repository take their directory as their project. Before this, only OpenCode runs started through AOP were counted ([`25af75d`](https://github.com/wakamex/clanker-analytics/commit/25af75d72cf6cbea0419234de5d57f4794c6f79f), [`7af43d1`](https://github.com/wakamex/clanker-analytics/commit/7af43d1fb9fb562ab02b255f29fbf88774e8eae2), [`f275321`](https://github.com/wakamex/clanker-analytics/commit/f2753213ffd0b4eaf5ad7dc39d8260a0817a5c92)).
- `pace --json` gives each quota window a price per percentage point, in `token_calibration.history`, from all its completed periods on the same plan, with the periods and dollars it rests on. Periods that used quota with no local cost are counted apart instead of pulling the price down. A window with no periods of its own takes a price derived from a sibling window of the same account, from how the two rose together ([`106ca67`](https://github.com/wakamex/clanker-analytics/commit/106ca6730bd3d45a7e29f511c9dc7f1f3d463cca), [`584795b`](https://github.com/wakamex/clanker-analytics/commit/584795bc048ac1935f5009385476720c15af4357)).
- `session-costs SESSION` prices a session of any harness clanker-analytics reads, not only Claude Code, and reports which harness it found ([`6214b32`](https://github.com/wakamex/clanker-analytics/commit/6214b322496b27f1f5d5f2802714a526e164977f)).
- An AOP run is attributed to the directory it worked in, which AOP records as `project_dir`, instead of the directory `aop` ran from ([`3b469d3`](https://github.com/wakamex/clanker-analytics/commit/3b469d34d54f93979228446e3f450e65ab3aea57)).
- Two clanker-analytics commands run at once now take turns on the cache instead of one failing on a DuckDB file lock ([`f275321`](https://github.com/wakamex/clanker-analytics/commit/f2753213ffd0b4eaf5ad7dc39d8260a0817a5c92)). `quota-history` takes 47 seconds instead of 230 on one host: rows are loaded through a file, where DuckDB's `executemany` tried to import pandas for each value ([`e96c197`](https://github.com/wakamex/clanker-analytics/commit/e96c19766369420191e6e68cfb84a20a7cbc33be)).
