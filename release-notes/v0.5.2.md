- Codex moves a conversation's log to `~/.codex/archived_sessions/` when it is archived, and those logs are now read. A log read before and after the move is counted once ([`339c3f5`](https://github.com/wakamex/clanker-analytics/commit/339c3f59edabc6c98dad8b5c597d71bdea8fcdc1)).
- Claude Code transcripts are read from the `projects/` directory of `CLAUDE_CONFIG_DIR` and of each config directory added to clanker-usage, besides `~/.claude` ([`339c3f5`](https://github.com/wakamex/clanker-analytics/commit/339c3f59edabc6c98dad8b5c597d71bdea8fcdc1)).
- Gemini CLI has written chats as JSON Lines (`chats/*.jsonl`) since April 2026, and only the older `.json` chats were read, so no Gemini CLI usage after March reached any report. Both formats are now read, a message Gemini CLI rewrote counts once, and the Gemini CLI home follows `GEMINI_CLI_HOME` ([`0511bdd`](https://github.com/wakamex/clanker-analytics/commit/0511bdd13588ebe09157ddadaecc729fbe00e621)).
- `value` names accounts as `pace` does, by the login's email, and adds `account_label` to `value --json`. Cache updates report only the source files that disappeared since the last write, instead of a total of every file ever missing ([`fe31690`](https://github.com/wakamex/clanker-analytics/commit/fe31690d5fc7e50dbe3d998c05ee018edf33595c)).
