clanker-analytics now counts Antigravity usage from the usage each model call recorded, instead of an estimate that overstated it many times over, and adds Muse Code.

- Antigravity transcripts carry no token counts, so Agy usage was estimated by charging each response the whole transcript before it as uncached input. Antigravity keeps the context inside the model's window and serves most of it from cache, so long sessions were overcounted: one 2,271-call session was estimated at 5,070 million tokens and $10,145, and its recorded usage is 353 million tokens, 95% of them cache reads, and $75. Agy now reports one row per model call from the generation metadata in `conversations/<session>.db`. Sessions without that database keep the estimate ([`a2eb310`](https://github.com/wakamex/clanker-analytics/commit/a2eb310d79d7fe0f63a711667262910159fce8af)).
- Muse Code, Meta's coding agent, is read from `${XDG_DATA_HOME:-~/.local/share}/muse/sessions/`, one row per model call, and `--tool muse` selects it. AOP runs of Muse are reported as the same tool ([`ba3182e`](https://github.com/wakamex/clanker-analytics/commit/ba3182e89b25f9ca6575fbe9b7e8949d1ea02fac)).
- The cache schema changed, so the first run after upgrading rebuilds the whole cache from the source logs. Usage whose logs are gone is kept, as in every rebuild.
