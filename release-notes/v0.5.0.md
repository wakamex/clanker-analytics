## Highlights

- Every view is now a command with its own options: `table` (the default), `chart`, `share`, `regime`, `sql`, `diagnose`, `cache`, `throughput`, `pace`, `value`, `quota-history` and `record-quota`. A bare `clanker-analytics` prints the table for the last 7 days instead of saving a chart. The 0.4 options such as `--table`, `--record-quota` and `--sql` still work with a deprecation warning; update scripts and services, such as a quota recorder unit, to the commands.
- New `diagnose`, `cache` and `throughput` reports show where token spending rose, when prompt caches went cold, and output tokens per second per day.
- A `value` report prices each subscription's latest week at API rates, with plans set by id or monthly price in a config file.
- Quota history covers every provider and keeps two Claude logins apart, and `pace` follows only the login in use.
- Claude's one-hour cache writes are counted and priced at their own rate, using [model-prices](https://github.com/wakamex/model-prices). Price data refreshes daily without a new release, and each cost report ends with a `pricing:` line naming the data that priced it.
- Codex sessions run through [Agent Orchestration Process (AOP)](https://github.com/wakamex/agent-orchestration-process) are counted once and priced at the model they ran. They were counted twice before, once from Codex's own log and once from the AOP run, with the AOP copy unpriced. A run whose model is recorded nowhere is priced as its tool's most-used model that day and labeled `assumed model`.
- The cache keeps the usage of source files it no longer finds, so pruned logs and runs from other directories no longer erase history, even through `--refresh` and schema changes.
- AOP results are read in AOP's `aop-token-usage-v3` format, where each run's usage is its own, from the state directories AOP lists in `~/.local/state/aop/state-roots`. Older records need `aop migrate-results`; until then their cached usage is kept. This corrects resumed Agy runs, which older results counted once per run, and finds AOP runs regardless of the working directory.
- Zcode usage and quota snapshots are collected, and Antigravity models are read from its conversation databases.
- Charts use Clanker Mono, a renamed 101 KB build of D2Coding. The package now ships with an MIT license, plus the font's OFL text and the Twemoji CC-BY 4.0 text.
